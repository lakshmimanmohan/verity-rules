# Pair-score formula experiment

Branch `exp-scoring`. Seed 42. Report only; nothing in `verity_rules/` changed and the learned weights are the v4 composite weights. Generated by `tools/scoring_experiment.py`.

Formulas. For a pair, *present* = columns with a value in both records, w = column weight, s = column similarity, W = sum of all weights.

- **S0** (current rule): sum(w*s over present) / sum(w over present). Missing columns are skipped and the rest rescaled.
- **S1**: sum(w*s over present) / W. Missing columns add 0 to the numerator; the denominator is the sum of all weights.
- **S2**: S0 * coverage, where coverage = sum(w over present) / W.
- **S3**: S0 * sqrt(coverage).

Negatives are hard negatives: candidate pairs (identical value in a highly distinctive column) that are not true duplicates, capped at 5,000. Best-cutoff errors = missed duplicates + false merges at the best single cutoff, in pairs.

Copy C = blank 50% of every column except `customer_id`; Copy C25 = blank 25% of every column except `customer_id` (`python tools/degrade.py data/customers.csv data/customers_degraded_C25.csv --seed 42 --blank ALL 0.25 --except customer_id`). Copy H and H2 are described in `validation/reliability_cc_results.md` and `validation/reliability_diagnosis_2.md`.
