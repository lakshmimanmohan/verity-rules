# Comparator variant experiment

Branch `exp-comparators`. Seed 42. Report only; `verity_rules/` default (`v0`) is unchanged. Generated by `tools/comparator_experiment.py`.

Variants. **v0**: current behavior. **v1**: EMAIL and DATE checks before the IDENTIFIER check; other IDENTIFIER columns stay exact. **v2**: v1, other IDENTIFIER columns compare after lowercasing and removing every non-letter, non-digit character (exact match on the result). **v3**: v1, other IDENTIFIER columns use Jaccard of adjacent character pairs (bigrams) of the same normalized value. **v4**: v3, and text_character columns (no embeddings) use the same bigram Jaccard instead of character-set Jaccard.

Notes. Mean similarity is over the same 5,000 random non-duplicate pairs (seed 42), pairs where both values are non-null. Learned reliability and composite weight are `learn_rules(..., comparator_variant=v)`; scoring for AUC and best cutoff uses the same variant and those weights. Hard negatives: candidate pairs that are not true duplicates (capped at 5,000). Best-cutoff errors = missed duplicates + false merges, in pairs. Bigrams: a one-character value is its own single gram; two values that normalize to nothing match only if equal as text.

**Repeat check: each variant on each dataset was run twice; every report and full learn_rules result was identical.**
